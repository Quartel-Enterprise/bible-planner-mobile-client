# annotations_filters_cleared

**Tier:** P2 | **Domain:** Verse annotations

Resetting every filter at once.

## When it fires

The user taps Clear in the filter bar, Clear all filters in the wide filter panel, or Clear filters on the no-results state. It also drops the search query.
