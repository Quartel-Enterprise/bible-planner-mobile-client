Spike Mac App Store (issue #204, 2026-07-28). App Compose Desktop assinado ad-hoc com entitlements MAS (`app-sandbox`+JIT+`disable-library-validation`+`network.client`) **funciona por completo**: Compose renderiza, rede/Supabase OK, prefs/DataStore/Room no container.

**Causa raiz do hang do Room (resolvida):** BundledSQLiteDriver extrai `libsqliteJni.dylib` para tmpdir e dá `System.load`; arquivos criados por processo sandboxed ganham `com.apple.quarantine` automaticamente, e `dlopen` de código em quarentena trava PARA SEMPRE (Gatekeeper sem UI; sem exceção, sem deny no sandboxd; corrotina suspensa → SQLITE_BUSY nos requesters). Provado com java agent: quarentena+adhoc trava; sem quarentena carrega (adhoc ou dev cert — assinatura irrelevante).

**Fix (validado fim-a-fim, DB criado no sandbox):** empacotar `libsqliteJni.dylib` (do jar sqlite-bundled, `natives/osx_arm64/`) dentro do .app e passar `-Djava.library.path=$APPDIR` — o NativeLibraryLoader tenta `System.loadLibrary` ANTES da extração. Alternativa: props `androidx.sqlite.driver.bundled.path`/`.name`. Não-sandboxed (.dmg) não é afetado (sem quarentena automática), mas o fix é inócuo e vale aplicar geral.
